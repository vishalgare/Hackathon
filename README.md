# 🌾 FarmWise — Smart Farming Scenario & Decision Simulator

FarmWise is a simulation-based decision-support prototype that helps users compare different farming scenarios based on crop, water availability, rainfall, planting schedule, farm area, and input usage.

## 🎯 Problem Statement

Farmers often need to make decisions under changing conditions such as limited water, rainfall variation, planting delays, and different input levels.

FarmWise allows users to modify these conditions and immediately compare their simulated impact on:

- Expected yield
- Water consumption
- Water deficit
- Estimated cost
- Expected revenue
- Expected profit
- Risk score
- Risk factors

## 💡 Solution

FarmWise provides two configurable scenarios:

- **Scenario A — Baseline**
- **Scenario B — Alternative**

The simulator calculates the outcomes for both scenarios and provides visual and numerical comparisons.

## ⚙️ Key Features

- Crop-specific simulation
- Water resource analysis
- Cost and profit estimation
- Risk scoring
- Risk breakdown by factor
- Scenario comparison
- Factor impact analysis
- Decision insights
- Interactive charts
- Explainable simulation results

## 🧠 Simulation Factors

The simulation considers:

1. Crop
2. Farm area
3. Water availability
4. Rainfall condition
5. Planting schedule
6. Input usage
